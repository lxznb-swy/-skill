# 分镜词写作流程

把用户已经逐镜指定的镜头方案扩写为可执行的分镜词，不代替用户设计镜头。使用中文描述，保留台词原语言。以下为用户默认要求；用户后续明确修改某项要求时以新指令为准，不自行设置绕过规则的例外。

## 执行顺序

1. 判断本次是生成、修改、核对还是仅阅读/分析，只完成所请求的范围。
2. 确认本次任务所属集数、单元和场景；未明确时执行单元与场景确认规则。
3. 检查用户是否已经逐镜指定镜头方案；未满足时执行第零项规则。
4. 检查四类材料及版本，缺项时执行第一项规则。
5. 在500字内详细分析人物与场景空间，建立站位及机位对应。
6. 对照剧本核对用户指定镜头中的台词、动作、声音和事件顺序。
7. 只扩写用户指定的镜头，使用模板落实所有必填字段并完成交付检查。

写新分镜前读取 [references/practice.md](references/practice.md) 的协作经验；局部修改只读相关部分。不要将历史案例中的具体人物、左右手、服装或房间布局机械应用于新项目。

## 第零项：用户决定拍什么镜头

用户拥有镜头设计权。不得仅凭剧本、导演阐述、剧情梗概或完整素材自行决定镜头数量、镜头拆法、拍摄主体、景别、机位、运镜、切点或反应镜头。

生成分镜词前，用户必须逐镜说明想拍什么。可接受的依据包括：

- 用户明确说明“镜头1拍……，镜头2拍……”，并给出各镜的核心主体、动作或画面意图。
- 用户在消息或其他材料中提供已经划分镜号和核心内容的逐镜方案，并明确要求按该方案扩写。
- 用户点名修改一个或多个现有镜头，并说明要改成什么样。

只有剧本、剧情段落、总时长、镜头数量上限或“帮我写成分镜”等笼统要求，不构成逐镜方案。此时只读取和分析材料，回复：“剧本已经读取。你还没有逐镜指定要拍什么，我不会直接生成分镜词。请从镜头1开始告诉我想拍的主体、动作或画面；我会严格按你的镜头方案扩写。”

- 不主动补齐用户尚未设计的镜头，不增加建立镜头、反应镜头、插入镜头、转场镜头或结尾复核镜头。
- 用户只指定部分镜头时，只扩写这些镜头；指出未指定的范围，但不代写。
- 可以根据已确认材料补足构图、人物占比、逐秒情绪、声音、表演重点、结束状态和防穿帮要求等执行细节，但不得改变用户指定的拍摄主体、动作、顺序、景别、机位或运镜。
- 用户没有给出某个会实质改变画面的关键选择时，先指出该项，让用户决定；不以“拍摄合理性”为由替用户新增或改拆镜头。

## 单元与场景确认规则

剧集可拆为多个单元，每个单元可以使用不同场景、站位图和场景资产。所有材料和镜头任务必须绑定到明确的“第几集、第几单元、什么场景”。

- 用户上传人物站位图或场景资产图时，若没有说明所属集数、单元和场景，不根据上传顺序、文件名或画面内容擅自归类。回复：“请告诉我，这张（或这组）材料属于第几集、第几单元，具体是什么场景？”
- 用户提出要写或修改分镜词时，若本次所属集数、单元或场景尚未明确，先询问：“这是第几集、第几单元、哪个场景？”在取得答案前不生成分镜词。
- 当前会话已经明确且用户没有切换任务时，可以沿用已确认的集数、单元和场景，不重复询问；但每次正式交付分镜词时，开头必须写明：“本次：第X集·第X单元｜场景：XXX”。
- 同一集不同单元的站位图和场景资产分别记录，不跨单元套用。用户切换单元或场景后，重新核对该单元对应材料。

## 第一项：四类材料必须齐全

生成分镜词前必须取得并读懂：剧本、导演阐述、人物站位参考图、场景资产图。分镜词大纲不再是必需材料；用户逐镜指定的方案按第零项处理。检查本次涉及的集数、单元、场景和版本；仅有文件名不等于已经取得内容。

- 当前会话已可用并已读取的材料可以沿用，不要求重复提交。合并文件可以包含几类材料，以实质内容判断。
- 不能自行补写缺失的导演阐述、站位或场景信息，假装材料已齐。
- 缺任何一类，回复：“现在还不行。按照你设定的分镜词流程，还缺少：……。补齐后才能生成分镜词。”列出实际缺项，不抢先试写镜头。
- 材料不可读时明确说明，不声称已看图。材料齐全但存在会改变拍摄的空间或剧情冲突时，先完成可确定的分析，再指出具体冲突并询问必要信息。
- 此门槛约束生成分镜，不阻止单独阅读、分析已有站位、核对已有稿件或总结规则。
- 人物站位图和场景资产图必须属于本次已确认的单元与场景；其他单元的同类材料不能补足本单元缺项。

## 第二项：站位分析决定构图

先分析真实空间、身体朝向、视线目标和摄影机方向。站位分析必须详细，但整份分析（含表格文字）控制在500字以内。优先写清：空间方向、每个人的具体位置、彼此前后左右及距离、身体朝向、视线目标、动作路径，以及这些关系对机位和构图的限制。必要时使用紧凑表格。

- 依据站位图和场景图，不凭空加门、楼梯、通道或移动家具。箭头含义不明时，不擅自认定为走位或视线。距离不可量测时标为近似，不冒充精确测量。
- 构图严格分“前景／中景／后景”。前景为空就写“无遮挡”，不要为凑层次加人物或家具。
- 写明机位在哪、朝哪里拍，以及平视/俯拍/仰拍；另写正面/左侧/右侧/背面拍摄。平视指机位高度，不等于正面，也不等于人物直视镜头。
- 写每个人在画面左中右、前后，哪一侧脸、肩或背朝向镜头，身体和视线分别朝哪个方向。人物自身左右与画面左右明确区分。
- 每镜注明取景范围与主要人物可见部分的画面高度占比。近景通常胸部以上，70%—80%可以是构图选择，但不是近景定义；比例应与画幅、裁切、留白和姿态相符。
- 多人分别注明主要人物占比与遮挡。局部特写注明手部等主体局部的高度占比；无人起幅注明人物占比0，再写入画后的占比。
- 按真实机位确定背景。极致虚化时仍保留必要的门洞、通道和站位轮廓；不能同一区域既全部虚化又要求细节清楚。
- 转机位不代表人物换位置；正反打重新换算画面左右，保持真实站位和视线轴线。不能为露正脸擅自让人物绕到对方前面。

## 第三项：严格遵循剧情与台词

逐字保留原剧本台词，不擅自增删、替换、重复或补台词。人物做什么、动作对象及事件顺序按剧本和用户明确修订执行。

可以细化已授权动作的可拍摄过程，不能新增改变事件的抓握、阻挡、转身、退步或情节。口吃、拖音、打断、对白重叠也须有剧本或用户依据。不同材料冲突时不能暗改台词。

## 第四项：情绪使用三层写法

每镜按“本镜情绪曲线＋逐秒可见表演＋人物表演重点”三层书写。情绪词负责定性，可见动作负责表演，人物动机负责解释，禁止项负责控制表演尺度。

### 本镜情绪曲线

先写人物在本镜中的起始情绪、触发因素和结束情绪，格式：“角色：起始情绪 → 触发或认识变化 → 结束情绪。”例如：“Elena：虚弱迷离 → 认出母亲后安心 → 想起Noah后认真坚定。”

- 情绪没有转折时写明持续状态和强度，例如：“Edward：始终沉重克制，听完请求后转为明确接受。”
- 只写当前镜头实际发生的变化，不把后续镜头的情绪提前。
- 情绪变化必须由台词、声音、动作、视线目标或剧情信息触发，不能无原因跳变。

### 逐秒可见表演

格式：“时间段：角色＋明确情绪词：面部动作或肢体动作。”必须保留愤怒、悲伤、难过、高兴、兴奋、紧张、恐惧、急切、安心、坚定等明确情绪词，不能只列动作。

- 用眼皮轻颤、眉心收紧、嘴唇分开、下颌绷紧、手指收拢、身体前倾等可执行动作；不写文学比喻、修饰性形容词、肤色变化、眼睛发光等效果。
- 每条描述正文不超过40字，时间标签不计；角色、情绪词、动作和标点计入正文。不要在一秒内堆积无法同时完成的动作。
- 严格逐秒：0—1秒、1—2秒、2—3秒……连续覆盖成片时长。结尾不足1秒按实际写，如3—3.5秒；0.5秒镜头只写0—0.5秒。
- 时间不跳段、不重叠、不超时；升格按成片时间填写。
- 多人同秒分别成条并标明角色，每名人物的每条正文不超过40字。
- 动作必须属于当前景别能够看见的部位。只拍脸时不能用画外攥拳证明情绪；手部不入画时不能用手势承担情绪变化。
- 情绪依人物处境和动机判断。发现求救机会可写急切，不能自动写成兴奋；身体虚弱不等于情绪软弱。

示例：
0—1秒：Elena虚弱：眼皮轻颤，呼吸浅慢。
1—2秒：Elena安心：视线逐渐聚焦画外母亲。
2—3秒：Elena挂念：眉心轻收，准备开口。

## 第五项：人物表演重点

每镜单列“人物表演重点”，写清以下四项，并与逐秒细节对应而不全文重复：

- 核心动机：人物真正担心、保护、隐瞒或想达到什么。
- 情绪强度：情绪是克制、压住、逐渐增强还是突然爆发。
- 表演节奏：何时呼吸、停顿、换气、转移视线或开始动作；对白镜头可注明在哪个词后停顿或换气。
- 禁止表演：指出容易演错的方向，如“不突然惊醒”“不哭喊”“不大幅点头”“不演成委屈诉苦”。

表演重点解释“为什么这样演、演到什么程度”，不能只写“表演到位”“自然一点”，也不要逐字重复人物情绪细节。

## 第六项：结束状态与防穿帮要求

每镜两项均不可省略。

“本镜头结束状态”：明确人物位置、身体及视线方向、动作完成程度、接触/抓握关系、道具和场景状态。下一镜从此继续。

“防穿帮要求”：针对当前镜头明确画面左右、左右手、道具、服装首饰、支撑关系、门的状态、动作先后、声源位置和禁止入画的内容。保留用户具体禁止项，不把历史项目所有限制机械复制到新项目。

## 第七项：达到6秒的对白镜头由用户决定拆法

用户指定的对白镜头成片时长大于等于6秒（恰好6秒也触发）时，检查用户是否已经指定拆镜方式。不得自行增加听话者反应镜头或改动镜号。

- 用户尚未说明拆法时，指出该镜达到6秒，请用户决定切点、听话者和镜号；在决定前不生成该镜的完整分镜词。
- 用户明确要求按“说话者前半段＋听话者反应、原说话者画外音说完”的方式拆分时，才按原文切开，保证跨镜连续、不重复、不遗漏。
- 用户已经指定其他切法时严格执行，不替换成默认反应镜头。
- 若时长容不下完整台词，说明冲突并等待用户决定调整时长或拆法；不能删词、强行超速或暗改时长。
- 无对白长镜头不触发本项。

## 完整输出模板

仅对用户已经逐镜指定的镜头使用以下模板。正式输出前先标注本次集数、单元和场景。默认9:16竖屏，用户指定其他画幅时以其为准。每镜选用用户指定的场景视图；用户未指定但允许依据站位补足时，只能从本单元已提供的场景视图中选择并注明名称或编号，不把推测的新视图冒充已有资产。

```text
镜头编号
场景：
场景资产参考：
时长：X秒（成片时长）
景别：
运镜方式：
构图：
画幅、机位位置与高度、拍摄方向、取景范围。
前景：
中景：人物位置、露出哪一面、身体朝向、视线、画面高度占比。
后景：实际可见背景及虚化程度。
画面内容：按时间顺序写具体动作。
对白：标记说话者并保留原文；无对白注明。
声音：依项目要求写声源和表现。
本镜情绪曲线：
角色：起始情绪 → 触发或认识变化 → 结束情绪。
人物情绪细节：
0—1秒：角色＋情绪词：面部或肢体动作。
1—2秒：角色＋情绪词：面部或肢体动作。
按实际成片时长逐秒续写。
人物表演重点：核心动机、情绪强度、表演节奏、禁止表演。
本镜头结束状态：
防穿帮要求：
```

## 交付检查

- 本次集数、单元和场景已明确，并在交付开头标注；使用的站位图和场景资产属于该单元。
- 用户已逐镜指定镜头方案，输出的镜号、数量、主体、动作、顺序、景别、机位和运镜没有越权改动。
- 四类材料齐全、图文实际已读，名称和版本准确。
- 台词逐字完整、顺序正确，拆镜拼接后等于原文；剧情无擅改。
- 构图有三层、机位高度、拍摄方向、人物朝向与明确高度占比；背景符合空间。
- 每镜有完整情绪曲线，起始、触发和结束状态符合剧情且不提前。
- 逐秒情绪每条有角色、情绪词和可见动作，正文≤40字，连续覆盖成片时长。
- 表演重点包含核心动机、情绪强度、表演节奏和必要的禁止表演，不与逐秒细节机械重复。
- 每镜有结束状态和具体防穿帮要求。
- ≥6秒对白镜头已有用户确认的拆法；语速与动作量可实现；总时长由各镜相加核对。
- 相邻镜头左右、道具、门缝、抓握及动作进度连续，同一声音不重复触发。
- 不新增用户未指定的镜头。用户批准拆分后同步更新镜号和交叉引用；用户要完整镜头时交付其指定范围的完整稿，不只给修改意见。
